# 🍕 Pizzaria — Landing Page

Landing Page funcional para uma pizzaria, desenvolvida com **HTML5, CSS3 e JavaScript puro**, com foco em apresentar produtos, proporcionar uma navegação intuitiva e oferecer uma experiência agradável ao usuário.

## 🚀 Sobre o projeto

O projeto consiste em uma página web para uma pizzaria, desenvolvida com design moderno, interface responsiva e funcionalidades interativas.

A aplicação foi construída para simular a presença digital de uma pizzaria, permitindo que os clientes conheçam o cardápio, visualizem os produtos e interajam com a plataforma.

## ✨ Funcionalidades

- **Página inicial:** apresentação da pizzaria e destaques.
- **Cardápio:** exibição das pizzas e seus respectivos preços.
- **Interface interativa:** elementos dinâmicos utilizando JavaScript.
- **Responsividade:** adaptação para diferentes tamanhos de tela.
- **Navegação intuitiva:** acesso rápido às principais seções.
- **Experiência do usuário:** layout organizado e navegação simplificada.
